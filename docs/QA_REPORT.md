# QA 検証記録

## 2026-09-18 Q02

対象はローカル Next.js 開発サーバー（127.0.0.1:3100）、`APP_MODE=demo`・`JEV_MODE=mock`。

### 実施済み

`playwright test tests/e2e/api-invariants.spec.ts` で5テストが通過。

- 未認証で注文一覧は401、顧客の管理APIは403。
- 別顧客の相談の参照・変更と注文参照は404。
- 異なるOriginからの変更は403。
- 価格を追加した入力は422。M見積もり価格はサーバーで20,000円。
- 古いrevisionでの条件変更は409。
- 条件を変更した後の古い見積もりでの注文は409、注文は増えない。
- 同じ見積もり・冪等キーの同時注文2件が同じ注文ID・タスクIDを返し、注文一覧は1件。

初回テストで正当な127.0.0.1 Originも403となる不具合を検出。API担当がOrigin検証を修正し、上記テストで正常リクエストと異Origin拒否を確認した。

- 管理者の優先度変更は理由必須、変更履歴を追加。古いversionは409。
- 制作待ちから完了への飛び越し、完了からの再開を422で拒否。
- 管理者の状態変更が顧客の注文取得にも反映される。

- 同じclientMessageId・本文の再送は同じrevision/メッセージ件数を維持し、異なる本文での再利用は409。

### UI一連の検証：通過

`playwright test tests/e2e/order-flow.spec.ts` で1テスト通過。最終実行は最新Chromium1243、`playwright test` によりAPI5件とUI1件の計6件すべて通過（全体6.5秒）。
