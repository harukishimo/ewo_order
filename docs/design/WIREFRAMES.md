│        青い抽象画がほしい │ │ 予算     [20,000円]  │
│ 候補：抽象画 [確認する]   │ │ 希望日   [指定なし]  │
│ サイズを選んでください。 │ │ 補足     [青系…]     │

## 顧客：最終確認

```text
内容をご確認ください
M / 30×40cm · 抽象画
補足：青を中心とした落ち着いた雰囲気
希望日：指定なし（納期は未確約）
制作価格：20,000円（デモ料金）
見積もり有効期限：日時
制作依頼の受付です。決済は行いません。
[内容を修正]   [この内容で注文する]
```

## 顧客：モバイル

```text
Atelier                   注文一覧
絵の相談
デモ判定（該当時）
[ご希望の一枚 M / 抽象画      ▼]
[予算と価格に差があります（該当時）]
会話（ページ内スクロール）
候補・選択肢（折り返し）
[入力欄                 ][送信]
見積もり / 最終確認（条件充足時）
```

ブラウザキーボードと固定要素で入力欄が隠れないよう、強制的な画面全高固定は避ける。
